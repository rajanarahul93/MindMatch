# 🧠 MindMatch

**MindMatch** is a memory card game built using **React**, **TypeScript**, and **Styled Components**. Test your memory skills and enjoy the challenge of matching cards in a fun and interactive way!

## 🌟 **Live Demo**  
Experience the game live: [MindMatch](https://mind-match-topaz.vercel.app/#/)

---

## 📋 **Features**
- **Game Modes**: Select difficulty levels to match your skill.  
- **Responsive Design**: Enjoy the game on any device, from mobile to desktop.  
- **Dynamic Timer**: Tracks your performance and adds a sense of urgency.  
- **Restart & Pause Options**: Provides control over your game experience.  
- **Win Modal**: Celebrate your achievements when you complete the game.  
- **Light/Dark Themes**: Switch between themes for a customized experience.

## 🚀 **Getting Started**
Follow these steps to get a local copy of the project up and running:

### Prerequisites
- Node.js (v14 or higher recommended)  
- npm or yarn  

### Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/rajanarahul93/MindMatch.git
   cd MindMatch
   ```
2. Install dependencies:  
   ```bash
   npm install
   # OR
   yarn install
   ```
3. Start the development server:  
   ```bash
   npm start
   # OR
   yarn start
   ```
4. Open your browser and navigate to `http://localhost:3000`.
